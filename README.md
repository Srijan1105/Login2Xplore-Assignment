# Student Enrollment Form

A simple and responsive Student Enrollment Form project built using HTML, Bootstrap, JavaScript, jQuery, and JsonPowerDB (JPDB). This project allows users to save, update, and reset student records directly in the JsonPowerDB database.

---

## Description

The Student Enrollment Form is a web-based application designed to manage student details efficiently. Users can enter student information such as Roll Number, Full Name, Class, Birth Date, Address, and Enrollment Date.

The application integrates with JsonPowerDB for real-time database operations like:

- Saving new student records
- Updating existing records
- Fetching student data using Roll Number
- Resetting form data

The project uses:
- HTML5
- Bootstrap 5
- JavaScript
- jQuery
- JsonPowerDB API

# Benefits of using JsonPowerDB

## Why JsonPowerDB?

JsonPowerDB is a high-performance, lightweight, and easy-to-use database server that works well for web applications.

### Key Benefits:

- Simple and fast REST API-based database
- Schema-free JSON database
- Easy integration with frontend applications
- High performance and low latency
- Reduces backend development effort
- Supports real-time CRUD operations
- No need for complex SQL queries
- Lightweight and beginner-friendly

### Advantages in this Project

- Direct database interaction from frontend
- Easy record insertion and updating
- Fast data retrieval using Roll Number
- Minimal backend configuration required

# How to Run the Project

1. Download or clone the repository
2. Open the project folder
3. Open `Student_Enrollment_Form.html` in any browser
4. Ensure internet connection is enabled for:
   - Bootstrap CDN
   - jQuery CDN
   - JsonPowerDB API
